# HydraBand 

## รายละเอียดโดยย่อ
เป็นโครงงานระบบตรวจวัดชีพจร อุณหภูมิ และความชื้อนสัมพัทธ์เบื้องต้น โดยใช้ ESP32 เป็นหน่วยประมวลผลหลัก เพื่อรวบรวมข้อมูลจากเซนเซอร์หลายชนิด นำมาวิเคราะห์เพื่อประเมินความเสี่ยงเบื้องต้นจากHeat stroke
## Component
-IOXESP32 พอร์ต USB Type-C ตัวควบคุมหลัก อ่านเซนเซอร์และส่งข้อมูล

-MAX30102 สำหรับตรวจวัดอัตราการเต้นของหัวใจและประมาณค่าความอิ่มตัวของออกซิเจนในเลือด (SpO₂)

-GY-906-BCC (MLX90614) สำหรับวัดอุณหภูมิพื้นผิวแบบไม่สัมผัส 

-AHT20 สำหรับตรวจวัดอุณหภูมิและความชื้นสัมพัทธ์ของสภาพแวดล้อม

-LED5050 output แสดงสถานะของความเสี่ยงHeat stroke

## ESP32 
ทำหน้าที่รวบรวมและประมวลผลข้อมูลจากเซนเซอร์ทั้งสาม เพื่อนำค่าที่ได้มาวิเคราะห์ร่วมกันตามเงื่อนไขที่กำหนด จากนั้นแสดงผลข้อมูลและส่งการแจ้งเตือนไปยังโทรศัพท์มือถือผ่าน Bluetooth 

โครงงานนี้เป็นการประยุกต์ใช้เทคโนโลยีระบบสมองกลฝังตัว (Embedded Systems) และการวิเคราะห์ข้อมูลจากเซนเซอร์ เพื่อช่วยติดตามการเปลี่ยนแปลงของสัญญาณชีพและสภาพแวดล้อม โดยมีเป้าหมายเพื่อเพิ่มความสะดวกในการเฝ้าระวังความเสี่ยงจากHeat stroke ทั้งนี้ ระบบไม่ใช่อุปกรณ์วินิจฉัยโรคและไม่สามารถยืนยันภาวะขาดน้ำได้โดยตรง
